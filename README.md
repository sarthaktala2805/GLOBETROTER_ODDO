# BharatYatra

Phase 1 foundation for a responsive India travel-planning product.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3005`.

## Data policy

All destination, activity, stay, transport and budget content is local seed/sample data. It is intentionally labelled in the UI and is not presented as live or verified information. The repositories in `src/lib` are designed to be replaced by API-backed services in a later phase.
